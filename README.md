# 🌳 FamilyTree — Персональная система родословного древа

Легковесное, автономное веб-приложение для ведения, редактирования и визуализации родословной семьи с поддержкой нескольких деревьев, союзов/браков, подробных биографических карточек, архивных выписок и резервного копирования в JSON.

---

## Стек технологий

- **Backend**: Python 3.12, FastAPI, SQLAlchemy 2.0 (`Mapped` / `mapped_column`), Alembic, SQLite (WAL-режим), Pydantic v2
- **Frontend**: Svelte 5 + Vite (легковесный бандл ~40 КБ gzip, кастомная раскладка поколений и союзов на SVG/HTML Canvas с плавным Pan & Zoom и анимациями)
- **Инфраструктура**: Docker (multi-stage build) & Docker Compose
- **Тестирование**: `pytest` + `httpx` (Backend API) и `vitest` (Frontend граф и раскладка)

---

## Быстрый запуск одной командой (Docker Compose)

```bash
docker compose up --build -d
```

После сборки приложение будет доступно по адресу:
- **Веб-интерфейс**: [http://localhost:8000](http://localhost:8000)
- **Swagger / OpenAPI документация**: [http://localhost:8000/docs](http://localhost:8000/docs)

Файл базы данных SQLite автоматически сохраняется в папку `./data/family_tree.db` на хост-машине (или VPS).

---

## Локальный запуск для разработки и запуск тестов

### 1. Backend и тесты API (`pytest`)
```bash
python -m venv .venv
.\.venv\Scripts\pip install -r backend/requirements.txt
cd backend
..\.venv\Scripts\alembic upgrade head
..\.venv\Scripts\pytest -v
..\.venv\Scripts\uvicorn app.main:app --reload --port 8000
```

### 2. Frontend и тесты раскладки (`vitest`)
```bash
cd frontend
npm install
npm test
npm run dev
```

## Основные возможности

1. **Несколько независимых деревьев**: создание, переименование и удаление отдельных родословных веток (например, отцовская и материнская линии).
2. **Интерактивный граф с плавной анимацией**:
   - Автоматическая раскладка по поколениям и супружеским парам.
   - Плавные кривые Безье и подсветка прямой линии родства (предков и потомков) выбранного человека.
   - Масштабирование колесиком мыши, перетаскивание полотна, фокусировка на выбранной персоне и кнопка «Вписать всё».
   - Переключение между светлой и тёмной темой оформления.
3. **Подробное досье человека**:
   - **Основные данные**: ФИО, девичья фамилия, пол, годы и точные даты жизни, признак приблизительной даты (`ок. 1890 г.`).
   - **География**: место рождения, проживания, ухода из жизни и захоронения.
   - **Социально-исторические поля**: профессия/чин, образование, сословие, вероисповедание, происхождение.
   - **Архив и биография**: архивные шифры (фонд, опись, дело, лист) и текстовая биография.
4. **Контекстное управление связями**:
   - Добавление **Родителя**, **Супруга(и)**, **Ребенка** или **Брата/Сестры** прямо из карточки человека (как созданием новой анкеты, так и привязкой уже существующего в древе человека).
   - Безопасное удаление: удаление человека или союза не удаляет каскадно остальных членов семьи.
5. **Реестр персон и мгновенный поиск**:
   - Поиск по ФИО, девичьей фамилии, году, профессии или месту рождения.
   - Таблично-карточный реестр всех людей с фильтрацией по полу и сортировкой по старшинству/алфавиту.
6. **Экспорт / Импорт и Демо-режим**:
   - Выгрузка всего древа в один `.json` файл для бэкапа и восстановление из него в один клик.
   - Кнопка **«✨ Демо»** для мгновенной генерации примера родословной в 4 поколениях.
